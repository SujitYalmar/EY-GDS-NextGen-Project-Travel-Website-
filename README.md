# EY GDS NextGen – Travel Booking Website 🌍

During an internship with EY GDS & AICTE under the Edunet Foundation, this project was developed as a full‑stack travel booking web application using React.js on the frontend and Java Spring Boot with MySQL on the backend. It includes modules such as destination listings, booking forms, authentication, and data handling, and was built using Git and agile practices to ensure a responsive UI and smooth user experience across devices.

## ✨ Features

- Role-based authentication for hosts and travelers  
- Property listing with search filters (location, price, property type)  
- Real-time booking management with availability calendars  
- Reviews and ratings for properties  
- Integrated payment flow for secure transactions (design-ready)  
- Responsive UI optimized for desktop and mobile  
- Map integration concept for visualizing property locations[web:1]
